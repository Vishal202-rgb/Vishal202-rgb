## 🚀 Featured Projects

### 1. ResearchAI — Multi-Agent AI Research Platform
A MERN-based research workspace that coordinates specialized AI agents to produce structured, source-cited research reports.

- Designed a multi-agent workflow with **Planner, Researcher, Analyst, Fact-Checker, and Synthesizer** agents powered by Google Gemini.
- Integrated real-time web search through **Tavily** and built a RAG pipeline for PDF/TXT uploads, chunking, embeddings, and Pinecone semantic retrieval.
- Connected a **Neo4j knowledge graph** for entity and relationship visualization.
- Added contradiction detection, evidence tracing, deep-dive research, workspace comparison, PDF export, and JWT authentication.

**Tech:** React, Node.js, Express, MongoDB, Gemini API, Tavily, Pinecone, Neo4j, RAG, JWT  
**Links:** [GitHub Profile](https://github.com/Vishal202-rgb) · [Portfolio](https://vishal15.netlify.app)

### 2. DevPlatform — AI Code Analysis Platform
A developer platform that connects GitHub repositories with an AI-powered code analysis pipeline.

- Implemented **GitHub OAuth** using signed state parameters and server-side token exchange.
- Built a Gemini-based analysis pipeline with strict JSON-schema output for quality scores, severity breakdowns, and issue-level recommendations.
- Added JWT authentication, ownership checks, file filtering, size limits, and **30+ automated tests**.
- Deployed the React application and serverless Express backend on Vercel.

**Tech:** React, Node.js, Express, MongoDB, Gemini API, GitHub OAuth, JWT, Vercel  
**Links:** [GitHub Profile](https://github.com/Vishal202-rgb) · [Portfolio](https://vishal15.netlify.app)

### 3. Movie Recommendation System
A hybrid recommendation engine combining graph relationships and semantic similarity.

- Used **Neo4j** for relationship-aware recommendations and graph traversal.
- Used **Pinecone** for metadata embeddings and vector similarity search.
- Combined graph and vector retrieval to support movie discovery.

**Tech:** Neo4j, Pinecone, Embeddings, Vector Search, Graph Traversal  
**Links:** [Repository](https://github.com/Vishal202-rgb/movie-recommendation)
