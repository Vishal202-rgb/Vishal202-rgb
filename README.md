## 🚀 Featured Projects

### 1. [ResearchAI — Multi-Agent AI Research Platform](https://github.com/Vishal202-rgb/ResearchAI-MultiAgent)

A research workspace that coordinates specialized AI agents to produce structured, source-cited research reports.

- Designed a multi-agent workflow with **Planner, Researcher, Analyst, Fact-Checker, and Synthesizer** agents powered by Google Gemini.
- Integrated web search through **Tavily** and built a RAG pipeline for document uploads, chunking, embeddings, and Pinecone semantic retrieval.
- Connected a **Neo4j knowledge graph** for entity and relationship visualization.
- Added evidence tracing, deep-dive research, workspace comparison, PDF export, and JWT authentication.
- **Live Demo:** [ResearchAI](https://research-ai-multi-agent-202.vercel.app/)

**Tech:** React, Node.js, Express, MongoDB, Gemini API, Tavily, Pinecone, Neo4j, RAG, JWT

### 2. [DevPlatform — AI-Powered Software Engineering Platform](https://github.com/Vishal202-rgb/DevPlatform)

An AI-powered developer platform that connects GitHub repositories with code analysis and software engineering workflows.

- Integrated GitHub repositories and built AI-assisted repository analysis workflows.
- Developed capabilities around code quality, security analysis, repository chat, test generation, and architecture exploration.
- Worked with multi-step AI workflows to analyze code and present actionable development insights.

**Tech:** React, Node.js, Express, MongoDB, Generative AI, GitHub API

### 3. [Skribbl.io Clone — Real-Time Multiplayer Drawing Game](https://github.com/Vishal202-rgb/scribble-clone)

A real-time multiplayer drawing and guessing game inspired by Skribbl.io, built with a live room-based experience.

- Implemented real-time gameplay using **Socket.IO**, including room creation, joining, and player synchronization.
- Built drawing tools with HTML5 Canvas, colors, brush sizes, eraser, and undo functionality.
- Added timed word selection, answer validation, hints, chat, avatars, and leaderboard features.
- Supports public/private rooms, room codes, and invitation links.
- **Live Demo:** [Play Skribbl Clone](https://scribble-clone-zeta.vercel.app/)

**Tech:** React, TypeScript, Node.js, Express, Socket.IO, HTML5 Canvas, Vite, Tailwind CSS

### 4. [AI Job Recommendation CLI](https://github.com/Vishal202-rgb/job-recommendation)

An AI-powered command-line tool that analyzes a candidate's resume and recommends relevant job opportunities.

- Parses PDF resumes and uses Gemini to analyze candidate skills and experience.
- Uses embeddings and semantic retrieval to find relevant job matches.
- Integrates Pinecone for vector search and Neo4j for graph-based relationships.
- Provides job recommendations, ATS-style matching insights, missing skills, and a learning roadmap.

**Tech:** Python, Google Gemini, Embeddings, Pinecone, Neo4j, PDF Parsing

### 5. [DevVoice — Voice-First Developer Assistant](https://github.com/Vishal202-rgb/HackBlr_DevVoice)

A voice-first developer assistant designed to help developers interact with technical knowledge and documentation.

- Built a browser-based voice interaction experience.
- Developed a RAG workflow with document parsing, chunking, embeddings, and Qdrant retrieval.
- Added support for technical knowledge retrieval through a conversational interface.

**Tech:** Next.js, TypeScript, Tailwind CSS, Qdrant, RAG, Browser Speech API

### 6. [Movie Recommendation System](https://github.com/Vishal202-rgb/movie-recommendation)

A hybrid recommendation engine combining graph relationships and semantic similarity.

- Used **Neo4j** for relationship-aware recommendations and graph traversal.
- Used **Pinecone** for metadata embeddings and vector similarity search.
- Combined graph and vector retrieval to support movie discovery.

**Tech:** Neo4j, Pinecone, Embeddings, Vector Search, Graph Traversal

### 7. [RecoverAI — Failed Payment Recovery Platform](https://github.com/Vishal202-rgb/recoverai)

A fintech-focused application concept designed to analyze and support failed-payment recovery workflows.

- Explored AI-assisted analysis for failed payment scenarios.
- Added safety-oriented rules and recovery simulation workflows.
- Built a full-stack application foundation for payment recovery experiences.

**Tech:** React, Node.js, Express, MongoDB, Google Gemini

### 8. [Track Condition Detector](https://github.com/Vishal202-rgb/track-condition-detector)

A computer-vision application that classifies track conditions from uploaded images.

- Classifies track images into **Dry, Damp, Wet, and Drying** conditions.
