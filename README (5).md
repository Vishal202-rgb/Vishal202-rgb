### 1. [ResearchAI --- Multi-Agent AI Research Platform](https://github.com/Vishal202-rgb/ResearchAI-MultiAgent)

A MERN-based research workspace that coordinates specialized AI agents
to produce structured, source-cited research reports.

-   Designed a multi-agent workflow with **Planner, Researcher, Analyst,
    Fact-Checker, and Synthesizer** agents powered by Google Gemini.
-   Integrated real-time web search through **Tavily** and built a RAG
    pipeline for PDF/TXT uploads, chunking, embeddings, and Pinecone
    semantic retrieval.
-   Connected a **Neo4j knowledge graph** for entity and relationship
    visualization.
-   Added contradiction detection, evidence tracing, deep-dive research,
    workspace comparison, PDF export, and JWT authentication.

**Tech:** React, Node.js, Express, MongoDB, Gemini API, Tavily,
Pinecone, Neo4j, RAG, JWT

### 4. [AI Job Recommendation CLI](https://github.com/Vishal202-rgb/job-recommendation)

A terminal-based AI tool that analyzes a PDF resume and recommends
relevant roles based on semantic matching.

-   Extracts skills, education, projects, and experience using **Gemini
    2.5 Flash**.
-   Matches resume content against job descriptions using embeddings and
    semantic similarity.
-   Models User → Skills → Jobs relationships with **Neo4j** and
    supports **Pinecone** vector search.
-   Generates a Top 5 job list, match percentages, missing skills, ATS
    score, and a personalized learning roadmap.

**Tech:** Node.js, Gemini 2.5 Flash, Pinecone, Neo4j, Embeddings, PDF
Processing

### 5. [DevVoice --- Voice-Native Developer Assistant](https://github.com/Vishal202-rgb/HackBlr_DevVoice)

A voice-first developer assistant MVP that combines technical Q&A,
debugging support, and semantic retrieval over uploaded reference files.

-   Supports push-to-talk and continuous listening with live transcripts
    and spoken responses.
-   Provides developer modes for explaining code, debugging errors,
    summarizing documentation, and suggesting fixes.
-   Implements file parsing, chunking, embeddings, and Qdrant-backed RAG
    with a local in-memory fallback.
-   Includes session history, browser persistence, and mock mode for
    demos.

**Tech:** Next.js 15, TypeScript, Tailwind CSS, Qdrant, RAG, Web Speech
API
